# 我的产品之路

个人产品博客。静态站点的公开目录为 dist，使用锚点路由组织首页、面试栏目、训练目录和逐题阅读页。

## 内容维护

`dist/content.json` 包含训练集、主题与问答。新增栏目时，在首页及导航增加入口，并在 `dist/app.js` 中增加相应页面。现有三个训练集共 133 题：通用面试训练 80 题（12 类），常见问题训练 30 题（9 类），AIGC 多模态内容训练 23 题（2 类）。

通用训练以用户提供的一题一答合并版为准；其他训练使用原站当前回答，保留思路、口述路径及来源。此博客提供阅读与逐题自测；原站的答案编辑与跨设备学习状态仍在原站使用。

四份面试复盘共 31 条，25 条对应既有问题、6 条新增题。每条保留原始问法、回答反馈、表格参考回答和来源行号，存储在 questions[].reviews。原有 127 道题的主回答保持不变，差异口径在对应复盘中说明。
